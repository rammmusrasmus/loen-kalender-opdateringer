# Løn-kalender — opdateringer

Her ligger kun de færdige Windows-installationsfiler til Løn-kalender, så programmet kan opdatere sig selv.
Kildekoden ligger ikke her.

Hent den nyeste version under **Releases** og kør `Løn-kalender Setup x.y.z.exe`.
Når programmet er installeret, finder det selv nye versioner (Profil → Søg efter opdatering).
